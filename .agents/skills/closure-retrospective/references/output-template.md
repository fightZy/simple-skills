# Output Template

Read this file only after at least one candidate survives the decision rubric.

```markdown
# Closure Retrospective

## [short title]

- Evidence: [observable decision and outcome from the current task]
- Mechanism: [why the decision caused, protected, or improved the outcome]
- Guidance: [future trigger -> concrete action -> verification signal]
- Placement: [verdict] -> [target artifact and section]
- Boundary: [include only when omitting a limit could cause misapplication]
- Tradeoff: [include only when maintenance cost or risk is non-obvious]

If you approve, I will apply the suggested edits.
```

Omit `Boundary` and `Tradeoff` entirely when their conditions do not apply. Use an unnumbered recommendation heading when one candidate survives; number headings only when multiple independent candidates survive. Include at most three as a ceiling, not a quota. Do not include patch text or imply that edits already happened.
